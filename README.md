A computer that runs The Astra Hospitality already includes the Astra Agent and does not need both.

## Requirements

- Windows 10 or Windows 11, 64-bit
- An internet connection for the first sign-in

## Installing

1. Download the installer for the computer and open it.
2. If Windows shows **Windows protected your PC**, choose **More info**, then **Run anyway**.
3. Follow the steps. The app opens when installation finishes.
4. **The Astra Hospitality:** sign in with your POS account.
   **Astra Agent:** enter the 7-character Astra Agent code. A manager finds it in the POS under **Settings › Password › Astra Agent**.

## Updates

There is no need to download again. Screens, menus and prices update by themselves, and **Refresh** (F5) fetches the latest at once. New versions of the apps download in the background and install automatically.
